Repository data policy

FU-TCM 的当前分支仅提交代码、提示词、配置和说明文档。原始材料、生成数据、训练/测试集、图像、压缩包和 benchmark 样本保持在本地。

Before committing

git status --short
git ls-files | LC_ALL=C grep '[^ -~]'
git check-ignore -v <local-data-path>

第二条命令应无输出；第三条命令应显示对应的 .gitignore 规则。若确实需要发布数据，请使用单独的数据仓库或受控存储，并先完成授权、隐私和许可检查。
