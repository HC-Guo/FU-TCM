FU-TCM model overview

FU-TCM 是面向中医知识理解、多模态诊察、临床推理与结构化辨证训练的多模态大语言模型。

Model configuration

Base modelQwen3.5-9B
ModalitiesText and image
Supervised alignmentFull-parameter SFT
Reasoning alignmentverl GRPO
SFT context length4,096 tokens
Training stackbf16 · DeepSpeed ZeRO-3 · LLaMA-Factory

Core capabilities

中医知识理解

理解古籍、方药、医理、教材与临床知识，完成有依据的中医问答。

多模态诊察理解

处理舌诊、面诊、中药图像与医学图文信息。

结构化辨证推理

分析四诊、八纲、脏腑、气血津液和病因要素。

证型判断

根据临床证据组织辨证过程，并输出明确证型。

GRPO alignment objective

20%格式与推理结构
40%证型一致性
40%辨证参数一致性

奖励函数同时约束推理结构和最终证型，而不只评价回答是否流畅。
