FU-TCM training

训练分为领域监督微调、辨证推理对齐和模型评测三个阶段。

1

Full-parameter SFT

使用 Qwen3.5-9B、文本与图像指令样本、DeepSpeed ZeRO-3、bf16 和 4,096 token 上下文完成中医领域全参数微调。

llamafactory_qwen35/qwen35_9b_full_sft_ds3.yaml

2

GRPO reasoning alignment

通过格式、证型和辨证参数奖励，使模型学习四诊到八纲、脏腑、气血津液、病因和证型的结构化推理。

reward_functions.py::compute_score

3

Evaluation

使用 Transformers 或 vLLM 运行文本和视觉评测，并按数据集与类别统计准确率。医生盲测工具用于独立人工评价。

eval_qwen35.py · eval_qwen35_vllm.py
