Classical Text QA

This module generates categorized question-answer material from classical TCM texts, cleans the output, and converts it to the SFT schema.

Main entry points

PathRole
scripts/generate/generate_qa_01.pyEntry point for one QA category; the directory contains the remaining categorized generators.
scripts/process/clean_and_export.pyClean and export generated questions.
scripts/process/convert_to_sft_format.pyConvert cleaned material to the SFT schema.
