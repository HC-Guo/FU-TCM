Meta-reasoning case conversion

Convert local meta-reasoning cases to the structured bianzheng schema and verify the intermediate diagnostic fields.

Execution order

python scripts/convert/convert_bianzheng.py
python scripts/verify/verify_bianzheng.py

Environment variables

export OPENAI_API_KEY="<your-api-key>"
export OPENAI_BASE_URL="<openai-compatible-base-url>"
export META_REASONING_MODELS="<comma-separated-model-names>"

Core files

PathRole
data/raw/Local source cases; excluded from Git.
data/processed/Local conversion and verification outputs; excluded from Git.
